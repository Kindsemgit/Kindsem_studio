# AGENTS_FRONTEND.md

Правила вёрстки и клиентского JavaScript.  
Применяются, **если не противоречат** существующей структуре проекта.

**Вёрстка — только Mobile-first.** База в `styles.css` — узкий экран. Шире — только `min-width` в `media.css`. Не пиши сначала десктоп и не сужай через `max-width`.

**Нельзя:** desktop-first, `@media` в `styles.css`, обычные стили в `media.css`, `!important`, стили по `#id`, JS инлайн (`onclick`, логика в `<script>`), новые CDN/библиотеки, писать в `window`, пустой `catch`, `docs/` рядом с вёрсткой.

## Структура папок (только для новых проектов)

При создании проекта с нуля:

```
index.html      — корень фронтенда, UTF-8 без BOM
css/
  styles.css    — база: узкий экран, без @media (mobile-first)
  media.css     — только @media (min-width), набор точек один на проект
js/             — все файлы .js
fonts/          — файлы шрифтов
img/            — растр и иконки
```

- Документация — корневые `README.md` и `docs/` (только `.md`), не рядом с вёрсткой.
- `AGENTS.md` остаётся в корне репозитория, не в `docs/`.
- Уже существующую раскладку не переименовывай и не переноси без просьбы.

## HTML

- Семантика по смыслу: `header`, `nav`, `main`, `section`, `article`, `button`, `label`, списки, заголовки. Не заменяй семантику на набор `div`/`span`.
- В `index.html`: `<meta charset="UTF-8">`, `lang` на `<html>` (язык интерфейса).
- Подключение: `css/styles.css` → `css/media.css` → скрипты из `js/`.
- У каждого поля формы есть `label`. У содержательных картинок — `alt` (декор — пустой `alt`).
- У `<img>` заданы `width` и `height`. Не растягивай так, чтобы плыли пропорции (`object-fit` / явный размер).

## CSS

- **БЭМ только для вёрстки**: `блок`, `блок__элемент`, `блок--модификатор`. Не применять к Python, именам модулей, функций, JSON.
- Цвета, шрифты, отступы, размеры — через кастомные свойства (`:root` / `--color-…`, `--font-…`, `--space-…`, `--size-…`). Не разбрасывай «магические» px/hex по селекторам, если токен уже есть.
- **Mobile-first (обязательно):** `styles.css` — как на телефоне. В `media.css` только `@media (min-width: …)`, чтобы добавить колонки/отступы на широком экране. Набор брейкпоинтов — один на весь проект.
- **Запрещены** `!important` и стили по `#id`. Исключение — чужой код, который иначе не перебить, с комментарием почему.
- `@media` — только в `media.css`. Не пиши `@media` в `styles.css` и не клади обычные стили в `media.css`.
- Кроссбраузерность: Chrome, Firefox, Safari, Edge — актуальные версии. Вендорные префиксы — только где ещё нужны.
- Доступность: полная навигация с клавиатуры (виден `:focus`), достаточный контраст. Смысл передавай не только цветом (иконка, текст, паттерн).

## JavaScript

- Код — в `js/`. Не пиши JS инлайном в HTML (`onclick`, `<script>` с логикой).
- Не подключай новые библиотеки и CDN без явной просьбы.
- Не пиши в `window` (глобальные функции, «синглтоны»). Исключение — крошечная точка входа, если без неё нельзя.
- Слушатели событий — на ближайшем общем родителе (делегирование), если элементов несколько или они появляются позже.
- Ошибки не глотай пустым `catch`. Минимум: `console.error` с контекстом или понятное сообщение пользователю / проброс ошибки наверх.
- Комментарии — только если без них неясно *почему*. Не комментируй очевидное.

## Проверка перед сдачей

- Переполнение: длинный текст, узкая колонка, flex/grid, картинки, таблицы, горизонтальный скролл страницы. Текст не должен вылезать из блока; контейнер — не раздувать документ вширь.
- Картинки лежат в `img/`, сжатые.

**Повтор:** вёрстка Mobile-first (`styles.css` = узкий экран, `media.css` = `min-width`), `@media` только в `media.css`, БЭМ и токены в `:root`, не инлайн-JS, у `<img>` есть `width`/`height`, перед сдачей проверь переполнение.
