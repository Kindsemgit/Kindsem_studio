# AGENTS_SECURITY.md

Правила работы с секретами и безопасностью.  
Дополняют пункт «Секреты» в `AGENTS.md`.

## Секреты

- `.env`, ключи, токены — не в git, не в логи, не в UI, не в ответы.
- Не читай и не печатай содержимое `.env`, ключей, паролей, токенов.
- Не предлагай коммитить `.env`, `credentials.*`, приватные ключи, дампы с секретами.
- Не вставляй секреты в HTML, клиентский JS, логи, скриншоты, примеры в чате.

## Сеть и опасные действия

- Не открывай сервисы в интернет без просьбы. Локальная панель — только localhost, пока не сказали иначе.
- Опасные действия (удаление данных, операции с деньгами и реальными аккаунтами, отзыв ключей, публикация) — только после явной просьбы.

## Служебные файлы ассистента

В git живут только корневые `AGENTS*.md`. Локальные: `CLAUDE.md`, `.claude/`, `.cursor/`, `.github/copilot-instructions.md` и подобные. Если среда читает свой служебный файл по умолчанию — создай его локально: короткий указатель «следуй корневому `AGENTS.md`», без копии всего текста. Не коммить и не предлагай `git add`. При необходимости добавь путь в `.gitignore`.

- Не коммить служебные файлы ассистентов (свои rules / instructions).
